# XCipherGo

**XCipherGo** is a Go-based application that allows you to encrypt and decrypt files using the AES (Advanced Encryption Standard) algorithm and a user-defined password. The project is split into two main branches:

- **`Web` branch**: A web-based interface for encryption and decryption.
- **`Program` branch**: A command-line tool (CLI) version for terminal usage.

---

## Features

- Encrypt and decrypt files using AES-256.
- Password-based encryption key.
- Simple and intuitive web interface (`web` branch).
- Fast and lightweight CLI tool (`program` branch).
- Works with any file type.
- Easy to build and run on Linux or Windows.

---

## Requirements

- Go 1.20 or higher.
- Web browser (for the web version).
